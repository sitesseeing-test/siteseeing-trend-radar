Framer Skills: Der Website-Agent lernt das Designsystem

← Alle Trends 25. September 2026

Seit dem 22. September kann man dem Framer-Agenten beibringen, wie ein Team arbeitet: Skills sind gespeicherte Anweisungen, die Designsystem, Schreibstil oder CMS-Abläufe festhalten und bei jeder Aufgabe wieder angewendet werden. Aus dem Prompt für den Einzelfall wird damit eine dauerhafte Arbeitsgrundlage.

Detailanalyse

Framer hat seinen Canvas-Agenten in den vergangenen Monaten Schritt für Schritt ausgebaut – zuletzt mit 3D-Transforms Anfang September. Mit Skills adressiert das Unternehmen nun das größte Problem agentischer Website-Tools: Inkonsistenz. Ein Skill ist ein benannter Anweisungsblock in den Projekteinstellungen, der per /skills-Befehl erstellt oder automatisch angewendet wird, wenn er zur Aufgabe passt.

Über @-Referenzen lassen sich konkrete Seiten, Komponenten, Textstile und Farbtokens als Vorbild einbinden. Framers Academy empfiehlt dafür eine klare Abstufung: „must“ für unverhandelbare Regeln, „prefer“ für bevorzugte Lösungen und „can“ für freie Entscheidungen. Besonders relevant ist, dass Skills beim Remixen eines Projekts erhalten bleiben – Template-Ersteller können damit Anleitungen mitliefern, wie neue Seiten und Inhalte korrekt ergänzt werden.

Framer: Mit Skills arbeitet der Agent innerhalb des Systems, statt die Website jedes Mal von Grund auf neu zu interpretieren.

Damit folgt Framer demselben Muster wie Figma, Webflow und Anthropic: Agent Skills werden zum Standardformat, in dem Designwissen maschinenlesbar gemacht wird. Für Teams verschiebt sich die Arbeit vom Pixel zum Regelwerk – wer seine Designentscheidungen nicht präzise formulieren kann, bekommt vom Agenten beliebige Ergebnisse. Spannend wird, ob Framer Skills künftig auch workspace-weit teilbar macht.

Für Siteseeing

Framer-Projekte mit Skill-Paket übergeben statt mit PDF-Styleguide

Viele Siteseeing-Kunden pflegen ihre Websites nach dem Launch selbst – und genau dort erodiert das Designsystem. Mit Framer Skills kann Siteseeing die Designregeln eines Projekts direkt im Tool hinterlegen, sodass Marketing-Teams neue Landingpages per Agent erzeugen, ohne gegen das System zu verstoßen. Das ist ein verkaufbares Übergabe-Paket: „Designsystem als Skill“ inklusive must/prefer/can-Regeln und Beispielseiten.

Sofortmaßnahme

Diese Woche für ein laufendes Framer-Kundenprojekt einen „Landingpage“-Skill mit fünf must-Regeln und zwei @-Referenzseiten anlegen und testen, ob der Agent eine neue Kampagnenseite systemkonform baut.
