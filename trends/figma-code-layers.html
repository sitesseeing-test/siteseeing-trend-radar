Figma Code Layers: Design und Entwicklung auf einem Canvas

← Alle Trends 26. Juni 2026

Auf der Config 2026 am 24. Juni präsentierte Figma Code Layers – die wohl folgenreichste Ankündigung der Konferenz. Das Feature verbindet Design-Canvas und GitHub-Repository in einer einzigen multiplayer Figma-Datei und macht den klassischen Handoff zwischen Design und Entwicklung strukturell obsolet.

Detailanalyse

Seit Jahren ist der Design-to-Dev-Handoff ein strukturelles Reibungsproblem in UX-Agenturen: Designentscheidungen werden in Figma getroffen, in Jira-Tickets übersetzt, von Entwicklern interpretiert – mit jedem Schritt steigt die Fehlerquote. Code Layers löst dieses Problem radikal: Teams können ein GitHub-Repository direkt auf den Figma-Canvas ziehen, npm-Packages importieren und einzelne Design-Layer mit einem Klick oder einem Prompt in Code-Layer umwandeln, die live mit dem Repository synchronisiert bleiben. Kein Export, keine Tickets, kein Interpretationsspielraum.

Das Ergebnis ist eine echte multiplayer Umgebung: Designer und Entwickler arbeiten gleichzeitig in derselben Figma-Datei. Ändert ein Designer die Komponente auf dem Canvas, sieht der Entwickler die Codeänderung im Repository – und umgekehrt. Die Frühzugangsphase beginnt im Juli 2026 für Nutzer mit Full Seat auf bezahlten Plänen. TechCrunch berichtete, dass Figma mit Code Layers direkt in Wettbewerb zu Cursor und anderen KI-Code-Editoren tritt.

Figma-CEO Dylan Field auf der Config 2026: „This is the merge of design and engineering we've been building toward for a decade." – das Feature positioniert Figma erstmals als vollständige Design-Engineering-Plattform.

Die Implikation für Designagenturen ist weitreichend: Wer Code Layers in den Workflow integriert, liefert nicht mehr nur Designs, sondern funktionsfähige UI-Komponenten direkt ins Repository des Kunden. Das verändert Abrechnungsmodelle, Übergabeprozesse und die Erwartungen an den Lieferumfang von Designprojekten fundamental.

Für Siteseeing

Design-Handoff neu definieren – vom Deliverable zur Integration

Code Layers verschiebt die Rolle der UX-Agentur: Wer dieses Feature beherrscht, kann Kunden anbieten, nicht nur Designs zu liefern, sondern funktionsfähige UI-Komponenten direkt in deren Repository zu integrieren. Das eröffnet neue Abrechnungsmodelle – Flat-Rate für Design plus Implementierung statt separater Phasen – und stärkt die Kundenbindung durch technische Integration. Für Siteseeing, das bereits Designsystem-Arbeit macht, ist Code Layers der nächste logische Schritt zur vollständigen Design-Engineering-Dienstleistung.

Sofortmaßnahme

Early-Access-Bewerbung für Code Layers unter figma.com/config-betas einreichen und ein Designer-Entwickler-Tandem-Testlauf mit einem aktuellen Kundenprojekt-Repository planen – um den Workflow vor dem offiziellen Launch zu dokumentieren.
